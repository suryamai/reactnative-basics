# 🍔 Food Delivery App — React Native & Expo

A modern, high-performance **Food Delivery Mobile Application** built with **React Native**, **Expo SDK 58**, **TypeScript**, and styled with a custom warm color palette (`#F5CB58`, `#F3E9B5`, `#E95322`, `#FFDECF`, `#391713`, `#F8F8F8`).

> 📖 **Full Project Documentation**: See [**`PROJECT_OVERVIEW.md`**](./PROJECT_OVERVIEW.md) for complete details on architecture, design system, features, and Python backend integration.

---

## ⚡ Quick Start

### 1. Start the App on Android Emulator

```bash
npx expo start --android
```

### 2. Run Type Checking & Linting

```bash
# Typecheck
npx tsc --noEmit

# Lint
npx expo lint
```
